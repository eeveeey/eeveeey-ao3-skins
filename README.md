### README Overview

# eeveey-ao3-skins

A collection of custom CSS site and work skins designed for [Archive of Our Own (AO3)](https://archiveofourown.org)

## Features

* **Custom Site Skins:** Visually distinct themes tailored for comfortable long-form reading and seamless browsing.
* **Plug-and-Play CSS:** Clean, well-commented code ready for immediate use.
* **Customization Friendly:** Easily tweak colors, fonts, and elements to fit your personal style.

## How to Use

1. Log into your AO3 account and navigate to your dashboard (`My Dashboard > Skins`).
2. Click on **Create Site Skin**.
3. Give your skin a descriptive title.
4. Copy the CSS code from your chosen skin in this repository and paste it into the **CSS** code box.
5. Click **Submit**, then scroll down and select **Use** to apply the skin.
